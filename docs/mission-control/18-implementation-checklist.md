## Phase 2: URL Intake and Workflow States

- [ ] URL input validation (strip whitespace, prepend https:// if missing)
- [ ] URL format validation before API call
- [ ] Build ID assigned on valid URL
- [ ] Workflow state enum defined in types
- [ ] State transitions logged to Supabase on every step
- [ ] Status: `URL_RECEIVED` on intake
- [ ] Status: `AUDITING_WEBSITE` on Firecrawl start
- [ ] Status: `SCORING_OPPORTUNITY` on audit complete
- [ ] Status: `GENERATING_DIRECTIONS` on direction generation start
- [ ] Status: `WAITING_FOR_APPROVAL` on direction generation complete
- [ ] Status: `LOCKING_BUILD_SPEC` on direction approval
- [ ] Status: `BUILDING_MOCKUP` on executor handoff
- [ ] Status: `QA_IN_PROGRESS` on executor return
- [ ] Status: `PREVIEW_READY` on QA pass
- [ ] Status: `OUTREACH_DRAFTED` on sales package complete
- [ ] Status: `WAITING_FOR_SEND_APPROVAL` on operator review
- [ ] Status: `COMPLETE` on deployment or outreach approval
- [ ] Status: `ERROR` on any critical failure
